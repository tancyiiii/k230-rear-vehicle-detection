# 320 与 640 模型对比

验证数据：1046 张图片、6014 个实例；上板环境为 CanMV K230 YAHBOOM 1G、固件 0.4.0。

| 指标 | 320 | 640 |
|---|---:|---:|
| Precision | 0.7707 | 0.8148 |
| Recall | 0.7056 | 0.7613 |
| mAP50 | 0.7580 | 0.8168 |
| mAP50-95 | 0.4416 | 0.4928 |
| 板端 FPS（纯车辆阶段） | 约 18~20 | 约 9.1 |
| KPU 推理 | 约 29 ms | 约 98 ms |
| Python 后处理 | 约 0.9 ms | 约 2.7 ms |

## 最终建议

- 实时报警优先：选择 320 版。
- 远距离和摩托车漏检较多、且能接受约 9 FPS：切换 640 版。
- 正式使用前必须重新标定测距和报警阈值。


## 人物模型补充

320 自动启动版本额外运行 COCO YOLO11n 人物模型。COCO128 上 person 类：mAP50 约 0.531，mAP50-95 约 0.407。车辆+人物双模型板端约 12.8 FPS；蜂鸣器使用 2700 Hz、duty=50。640 版本仍是纯车辆模型。
